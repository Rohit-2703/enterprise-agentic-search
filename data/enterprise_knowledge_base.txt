## Company Policies

### Vacation and Time Off Policy

All full-time employees are entitled to 20 days of paid vacation per year, accrued monthly at a rate of 1.67 days per month. Employees can carry over up to 5 unused vacation days to the next calendar year. Any days beyond this limit will be forfeited.

In addition to vacation days, employees receive:
- 10 paid holidays per year (dates vary by country)
- 5 sick days per year (no carryover)
- 3 personal days per year
- Unlimited mental health days (with manager approval)
- Parental leave: 16 weeks for primary caregiver, 8 weeks for secondary caregiver

Vacation requests must be submitted at least 2 weeks in advance through the HRIS system and require manager approval. During company blackout periods (end of quarter, major product launches), vacation may be restricted.

### Remote Work Policy

TechCorp operates on a hybrid work model. Employees are required to work from the office 3 days per week (Tuesday, Wednesday, Thursday are core days). Monday and Friday can be remote work days.

Fully remote positions are available for specific roles, subject to approval by department heads. Remote employees must maintain overlap with Pacific Time working hours (at least 4 hours between 9 AM - 5 PM PT).

All employees working remotely must:
- Have a dedicated workspace with reliable internet (minimum 50 Mbps)
- Be available during core hours for meetings
- Attend quarterly in-person team meetings (travel covered by company)
- Complete security training for remote work

### Expense Reimbursement Policy

Employees can expense business-related costs including:

**Travel Expenses:**
- Airfare: Economy class for domestic, premium economy for international flights over 6 hours
- Hotels: Up to $250/night in major cities, $150/night in other locations

- Meals: Up to $75/day ($15 breakfast, $25 lunch, $35 dinner)

**Equipment and Supplies:**
- Home office setup: One-time stipend of $1,000 for remote employees

**Other:**

All expenses must be submitted within 30 days with receipts via Expensify. Reimbursement is processed within 2 weeks.

### Code of Conduct

TechCorp is committed to maintaining a respectful, inclusive workplace. All employees must:

1. Treat colleagues with dignity and respect regardless of role, background, or identity
2. Maintain confidentiality of proprietary information and customer data
3. Avoid conflicts of interest and disclose any potential conflicts to HR

## Technical Architecture

### System Design Principles

All TechCorp products follow these core architectural principles:

1. **API-First Design:** Every feature must have a well-documented REST or GraphQL API before UI implementation
2. **Microservices Architecture:** Services are independently deployable and scalable
3. **Cloud-Native:** Built for Kubernetes with containerized deployments
4. **Security by Design:** Zero-trust architecture with encryption at rest and in transit
5. **Observability:** Comprehensive logging, monitoring, and tracing via OpenTelemetry

### Technology Stack

**Backend:**
- Languages: Python (FastAPI), Go (for high-performance services), Node.js (for real-time features)
- Databases: PostgreSQL (primary), Redis (caching), MongoDB (analytics)
- Message Queue: Apache Kafka for event streaming
- Search: Elasticsearch for full-text search

**Frontend:**
- Framework: React with TypeScript
- State Management: Redux Toolkit
- UI Library: Material-UI with custom design system
- Build Tool: Vite

**Infrastructure:**
- Cloud Provider: AWS (primary), GCP (disaster recovery)
- Container Orchestration: Kubernetes (EKS)
- CI/CD: GitHub Actions, ArgoCD
- Monitoring: Datadog, PagerDuty
- Secrets Management: HashiCorp Vault

### Security Practices

TechCorp maintains SOC 2 Type II, ISO 27001, and GDPR compliance.

**Security Requirements:**
- All code must pass security scans (Snyk, SonarQube) before merge
- Dependencies updated monthly with automated vulnerability scanning
- Penetration testing conducted quarterly by third-party firm
- Security training required for all engineers annually
- Data encrypted with AES-256 at rest, TLS 1.3 in transit
- Customer data isolated by tenant with separate encryption keys
- Access logs retained for 2 years for audit purposes

**Incident Response:**
- Critical vulnerabilities must be patched within 24 hours
- Security incidents escalated immediately to security team
- Post-incident reviews required for all P0/P1 incidents
- Customers notified within 72 hours of data breach (GDPR requirement)

## Engineering Processes

### Development Workflow

TechCorp follows a trunk-based development model with feature flags.

**Process:**
1. Engineers create feature branches from main
2. Code must include unit tests (minimum 80% coverage)
3. Pull requests require 2 approvals from team members
4. Automated CI runs tests, linters, security scans
5. Merge to main triggers deployment to staging
6. QA team validates in staging environment
7. Feature flags control rollout to production (1%, 10%, 50%, 100%)
8. Production deployment happens daily at 10 AM PT

**Code Review Standards:**
- PRs should be < 400 lines of code
- Description must include context, testing steps, and screenshots (for UI changes)
- Breaking changes require architecture review and migration plan
- All public APIs must have OpenAPI/Swagger documentation

### Release Schedule

- **Patch releases:** Weekly (Tuesdays) for bug fixes
- **Minor releases:** Monthly (first Wednesday) for new features
- **Major releases:** Quarterly for breaking changes

Release notes published on docs.techcorp.com with migration guides for breaking changes.

### On-Call Rotation

Engineering teams maintain 24/7 on-call coverage with weekly rotations.

**Responsibilities:**
- Respond to PagerDuty alerts within 15 minutes
- Investigate and mitigate incidents
- Write post-mortem reports for P0/P1 incidents
- On-call engineers receive $500/week on-call stipend
- Incident resolution after hours earns comp time (1.5x hours worked)

**Escalation:**
- P0 (service down): Immediate escalation to on-call engineer + manager
- P1 (major degradation): Response within 30 minutes
- P2 (minor issues): Response within 4 hours
- P3 (cosmetic): Addressed in next sprint
